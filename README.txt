MAMA NJERI'S KITCHEN - RESTAURANT WEBSITE
=========================================

PROJECT FILES
-------------
index.html  - Website structure and content
style.css   - Colours, layout, typography, responsive design and effects
script.js   - Mobile navigation, menu filters and demonstration order form

HOW TO OPEN THE WEBSITE
-----------------------
1. Extract the complete ZIP folder if you downloaded the ZIP file.
2. Open the mama-njeris-kitchen folder.
3. Double-click index.html to open the website in your browser.
4. To edit the website, open the folder in Visual Studio Code.

IMPORTANT NOTES
---------------
- The website is a one-page restaurant website for Mama Njeri's Kitchen.
- Food photographs are loaded from Unsplash, and Google Fonts are loaded online.
  An internet connection is needed to display these remote images and fonts.
- The food items, prices, location, opening hours and telephone number are sample
  details for this demonstration. Replace them with the restaurant's confirmed details.
- The order form is a front-end demonstration. It displays an order summary but
  does not send an order, accept payment or connect to a restaurant system.
- No external JavaScript libraries or frameworks are required.

GITHUB PAGES
------------
When publishing with GitHub Pages, upload index.html, style.css, script.js and
this README.txt into the repository's root folder. Then enable GitHub Pages
from the repository's Settings > Pages section.
